# PDF / 图片课表导入

版本 0.3.1，2026-11-09。

在「课程 → 导入课表」选择 PDF、PNG、JPG/JPEG 或 WebP。文件在当前设备解析，不上传原件；文字 PDF 优先提取原文字，扫描 PDF 和图片使用本地 OCR。CSV / JSON 导入继续保留。

## 核对与保存

1. 等待识别后，先核对学期名称、第一周周一、教学周数和学校作息。未找到的数据沿用当前课表，原表没有钟点时刻时必须自行核对。
2. 逐门核对名称、教师、教室、星期、节次和周次。可编辑、取消勾选、展开识别原文，或手工补充遗漏课程；图片可展开原图对照。
3. 未安排星期/节次的「其他课程」保留为待安排，补充时间后才会进入课表和小组件。无法解析的内容留在「未识别原文」。
4. 选择追加或替换。追加要求学期日期、周数和作息与当前一致；替换会覆盖旧课程和调课记录。存在重叠时再次提示，确认后统一保存并同步原生小组件。

识别页返回不会写入。一天有第 11 节或更多节次时，可先在「修改学期与作息」增加节次，再编辑课程；新增钟点为参考值。

## 支持范围

当前适配星期为列、节次为行的规则教务表格，单元格类似 `课程名/(9-10节)1-15周(单)/教室/教师`，支持同课程多组安排、单双周、不同教室和底部待安排课程。没有要求学校登录或执行第三方脚本。

长格线会先去除以改善 OCR。无效日期不会滚动成其他日期；OCR 开学日期不是周一时提示手工填写并暂沿用当前日期。部分星期标签缺字时按等宽表头补齐；缺节次须至少两行真实标签支持同一规律，才按格线推算。唯一合法的数字范围分隔符补全会显示警示，原文保留。不根据相似名称自动纠正课程或教师。

这不是任意版式通用识别器。歪斜照片、低分辨率、彩色叠字、复杂合并单元格、没有星期/节次标签或不同信息顺序可能产生遗漏。图片 OCR 即使读出了全部安排，也可能把课名、教师和教室读错，必须核对。多页表格重复安排会去重。

限制：PDF / 图片 20 MB，PDF 5 页，图片 4800 万像素；OCR 输入最长边统一为 3200 像素，每页 OCR 等待最多 90 秒。CSV / JSON 2 MB，一学期 300 门课程、每课 30 组安排、最多 16 节/天。加密或损坏的 PDF 显示错误，保留已有课表。

## 各平台实现

| 平台 | PDF | 图片 / 扫描页 | 当前验证 |
| --- | --- | --- | --- |
| Android 7+ | pdfrx / PDFium | ML Kit 中文 bundled SDK | Android 13 模拟器真实通道通过 |
| iOS 15+ | pdfrx / PDFium | 系统 Vision | App 与扩展已通过云端 Xcode 模拟器编译，识别运行仍待真机验证 |
| Web | PDFium WASM | Tesseract.js / WASM 中文模型 | 浏览器路径单独验证，见 VERIFICATION.md |

Web 的 OCR worker、WASM、模型与 PDFium 随站点打包，从当前站点加载，不依赖识别云服务；站点初次加载仍需网络，当前没有离线 PWA 启动保证。Android 使用预打包中文模型；ML Kit SDK 自身条款见第三方声明。

## 匿名与私人测试

`test/recognition_test.dart` 只使用匿名构造数据，覆盖空间坐标、周次、OCR 补全、页脚隔离、去重、待安排备份以及预览取消。

设备集成测试可临时创建 `private_fixtures/fixture.pdf` 和同版式 `fixture.png`，将该目录临时加入 pubspec 的 Flutter assets，再执行：

```sh
flutter test integration_test/document_recognition_test.dart -d <device> \
  --dart-define=RUN_PRIVATE_IMPORT_TEST=true \
  --dart-define=IMPORT_TEST_MEETINGS=<expected-count>
```

测试会输出识别内容，仅保存在本地。结束后移除临时资产声明与目录，再构建发行包。该目录已加入 `.gitignore`，但打包前仍应检查构建产物，避免个人课表被打入 APK、Web 或源码 ZIP。仓库不包含用户提供的原件、姓名、学号或完整提取结果。
