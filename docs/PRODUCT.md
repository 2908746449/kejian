# 课间 · 产品定义

## 首版目标

大学生在手机上建立一个学期的课表，快速确认下一节课的时间和地点，能够处理单次停课和跨周调课。以 Flutter 构建移动端，同时提供 Web 预览来评审界面与交互。

首版免登录，Android/iOS 将数据保存在 SQLite，Web 预览保存在当前浏览器。学期、课程、作息与单次变更可以导出为完整 JSON 备份。只读浏览、课程编辑和原生端本地保存无需服务器。

## v0.1 范围

- 三个页面：课表、课程、设置；窄屏底部导航，宽屏侧边导航。
- 首次启动加载明确标注的示例数据；可清除示例后建立自己的课表。
- 一份当前学期，1—52 周，日期按第一教学周的周一计算。
- 周视图、当前周定位、周次切换、今天高亮和下一节课。
- 课程增删改查；同课多组安排、自选周次、单双周快捷选择、不同教室。
- 单次停课、同周/跨周调课、修改本次教室、撤销变更。
- 时间冲突提示并允许保留；课表并排显示冲突课程。
- UTF-8 CSV 导入和模板下载；导入前预览，支持追加或替换。
- 版本化 JSON 完整备份、校验和恢复；写入失败不更新内存状态。
- 学期与作息编辑、是否显示周末。

当前每天默认 10 节，可编辑每节起止时间；备份模型允许 1—16 节。暂未提供在界面增删节次、同时管理多个学期、深色模式。

## v0.2 新增

- Android 原生桌面小组件，支持缩放、点击打开和完整学期快照。
- iOS 15+ WidgetKit 小、中、大尺寸扩展与 App Group 共享数据工程；尚待 Xcode 编译和设备验证。
- 下一节下方的剩余课程卡片：四门时下方三块，逐节减少；一块展开，当日只剩主卡时预览明天。
- 空格分隔的自定义周次，如 `1 3 5 8-12`，保留逗号与范围写法。

## 下一阶段

1. 根据首批同学反馈改进移动端信息密度和录入体验。
2. 补充手机真机测试，完成正式签名、应用图标最终稿和分发配置。
3. 本地提醒：权限拒绝处理、后台调度、调课后的重排、时区变化。
4. iOS 小组件真机验收与 Android 不同厂商桌面适配。
5. 首所学校导入器：使用真实课表样本验证，并为学校登录流程建立明确边界。
6. 多学期管理、深色模式、可调节字号与更多可访问性验证。

教务导入、账号同步、截图识别、成绩、作业、社交和自动排课不在当前实现中。开源仓库已准备在本地，不自动发布到 GitHub。

## 验收场景

同一门课每周两次、单双周、自选不连续周、同课不同教室；临时停课并恢复；跨周移动后原周只移除一次、目标周只增加一次；冲突课程均可点击；重新启动保留修改；备份往返保留全部字段；CSV 错误提供行号且不部分写入；非法备份不覆盖现有数据；本地写入失败不伪装保存成功。
