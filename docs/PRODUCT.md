# 课间 · 产品定义

## 首版目标

大学生在手机上建立一个学期的课表，快速确认下一节课的时间和地点，能够处理单次停课和跨周调课。以 Flutter 构建移动端，同时提供 Web 预览来评审界面与交互。

首版免登录，Android/iOS 将数据保存在 SQLite，Web 预览保存在当前浏览器。学期、课程、作息与单次变更可以导出为完整 JSON 备份。只读浏览、课程编辑和原生端本地保存无需服务器。

## v0.1 范围

- 三个页面：课表、课程、设置；窄屏底部导航，宽屏侧边导航。
- 首次启动加载明确标注的示例数据；可清除示例后建立自己的课表。
- 一份当前学期，1—52 周，日期按第一教学周的周一计算。
- 周视图、当前周定位、周次切换、今天高亮和下一节课。
- 课程增删改查；同课多组安排、自选周次、单双周快捷选择、不同教室。
- 单次停课、同周/跨周调课、修改本次教室、撤销变更。
- 时间冲突提示并允许保留；课表并排显示冲突课程。
- UTF-8 CSV 导入和模板下载；导入前预览，支持追加或替换。
- 版本化 JSON 完整备份、校验和恢复；写入失败不更新内存状态。
- 学期与作息编辑、是否显示周末。

当前每天默认 10 节，可在界面增删并编辑为 1—16 节。暂未提供同时管理多个学期、深色模式。

## v0.2 新增

- Android 原生桌面小组件，支持缩放、点击打开和完整学期快照。
- iOS 15+ WidgetKit 小、中、大尺寸扩展与 App Group 共享数据工程；0.3.1 已通过云端 Xcode 编译，尚待设备验证。
- 下一节下方的剩余课程卡片：四门时下方三块，逐节减少；一块展开，当日只剩主卡时预览明天。
- 空格分隔的自定义周次，如 `1 3 5 8-12`，保留逗号与范围写法。

## v0.3 新增

- 本地 PDF 文字提取与扫描页 OCR，PNG/JPG/WebP 图片识别。
- 识别核对页：学期、作息、每门课、选择范围、原文和未识别内容。
- 没有星期/节次的课程保留为待安排；允许后续补充时间。
- 作息支持在界面增加和移除节次，最多 16 节。
- Android PDF 与 OCR 设备集成测试；iOS Vision 代码与 iOS 15 配置保留，识别运行仍需真机验证。

## v0.3.1 新增

- Android 设置页直接请求添加到桌面，取消或失败后可重试；返回 App 后显示实际绑定数量。
- 小米 / 澎湃 OS 的安卓小部件入口说明，以及旧桌面图片预览。
- App 与内嵌 WidgetKit 扩展已通过 GitHub Actions 的 Xcode 模拟器编译，最低版本均为 iOS 15.0；真机 IPA 仍需签名。

## v0.3.2 新增

- 默认使用用户提供的凯里学院作息，设置中提供预设；旧默认钟点自动迁移一次，自定义作息保留。
- Android 与 iOS 保留原尺寸小组件，新增独立宽版入口；原版上下、宽版为横向长方形（Android 默认 4×2）、左右显示接下来的两门课，跨日期顺延，并显示时间、教室和调课标记。
- 作息表、旧数据升级及备份恢复行为见 `TIMETABLE_DEFAULTS.md`。

## v0.3.4 Android 安装兼容

- 按目标 ABI 打包完整原生库，压缩库由安装器解压，补齐 v1 / v2 / v3 签名。
- 提供更小的 arm64 APK、同文件 ZIP 和校验报告，保留原包名和证书以支持覆盖更新。
- Android 14 系统安装器完成覆盖安装与启动检查；澎湃 OS 真机的原始解析错误尚未复现。
- iOS 保持已发布的 0.3.3。

## v0.3.3 新增

- Android 恢复明确的 2×2 小方块，保留独立 4×2 入口，设置按钮与系统组件名称同步标注尺寸。
- 两端重新设计课程卡片：区别底色、突出课名和时间、填满可用高度；Android 4×2 适配较矮桌面。

## 验收场景

同一门课每周两次、单双周、自选不连续周、同课不同教室；临时停课并恢复；跨周移动后原周只移除一次、目标周只增加一次；冲突课程均可点击；重新启动保留修改；备份往返保留全部字段；CSV 错误提供行号且不部分写入；非法备份不覆盖现有数据；本地写入失败不伪装保存成功。
